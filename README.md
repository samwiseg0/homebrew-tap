# homebrew-tap

Homebrew formulae for my macOS tools.

## Install

```sh
brew install samwiseg0/tap/iairport
```

`brew tap samwiseg0/tap` is not needed. The command above adds the tap on first use.

## Formulae

- `iairport`. Wi-Fi roaming and link diagnostics for macOS. Built from source, so it needs the Xcode Command Line Tools. See [samwiseg0/iAirport](https://github.com/samwiseg0/iAirport).

## Update

```sh
brew update
brew upgrade iairport
```
